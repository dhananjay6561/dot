# Security policy

Dot runs entirely on your phone with no internet permission, so its attack surface is small. If you find a security problem, such as a way for another app to read your data through Dot, please report it privately.

Android may still copy Dot's playback, sound and UI preferences through encrypted system cloud backup or direct phone transfer. Dot excludes the music library, playlists, favourites, listening history, song paths, saved queue, lyric offsets and folder access grants from system backup; the separate Settings → Back up / Restore export is user-controlled.

## Reporting

Use **Report a vulnerability** on the repository's **Security** tab to open a private advisory. Please don't open a public issue for security problems.

Include the Dot version, your phone and Android version, and steps to reproduce. You'll get a reply as soon as possible, and fixes ship in the next release.

## Supported versions

Only the latest release receives fixes.
